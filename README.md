## Publication GitHub Pages

1. Fusionner la pull request après relecture.
2. Ouvrir **Settings > Pages** dans le dépôt.
3. Dans **Build and deployment**, choisir **Deploy from a branch**.
4. Choisir la branche **main**, puis le dossier **/docs**, et enregistrer.
5. Vérifier l'URL : https://dinhthierry.github.io/Power-BI---Portfolio/

Le site est statique (HTML, CSS, JavaScript), sans dépendance, sans compte Power BI et sans données personnelles. L'activation de Pages n'est **pas** automatique.

## Ajouter une réalisation vérifiable

Pour chaque projet, publier progressivement : le contexte, la source ou la nature anonymisée des données, le dictionnaire des indicateurs, les transformations Power Query, les mesures DAX, des captures du rapport réel et, si autorisé, le fichier `.pbix`. Distinguer explicitement données réelles, anonymisées et synthétiques. Ne jamais publier de données confidentielles ni de secrets.
